# 12주차 성적 데이터 분석

## 데이터

출처는 AI 협업 프로그래밍 12주차에 교수님이 배포한 실습 코드 ZIP이다. 원본 `scores_2026.csv`는 UTF-8이며, 정제 전 114행에서 정제 후 100행이 남았다.

| 열 | 뜻 |
| --- | --- |
| 학번 | 학생 식별 번호 |
| 이름 | 학생 이름 |
| 반 | 학생의 반 |
| 과목 | 평가 과목 |
| 점수 | 해당 과목의 평가 점수. 단위는 점이고 허용 범위는 0~100점이다. |

점수가 비어 있는 6행은 삭제했다. 실제 점수를 알 수 없고, 임의로 값을 채우면 반별 평균이 달라질 수 있기 때문이다. 같은 행이 반복된 4건을 제거하고 반과 과목 이름의 앞뒤 공백을 지운 뒤, 0~100점 범위를 벗어난 4행을 삭제했다.
